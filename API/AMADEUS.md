# Amadeus — retired for TripHub

Amadeus self-service shut down **17 Jul 2026**. New API keys cannot be issued from the old developer portal.

TripHub hotel search now uses **LiteAPI / Nuitee Connect**. See [LITEAPI.md](./LITEAPI.md).

`AMADEUS_API_KEY` / `AMADEUS_API_SECRET` are unused leftover env names and can be omitted.
